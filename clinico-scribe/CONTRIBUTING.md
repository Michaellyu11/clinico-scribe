# 贡献指南

感谢您对 ClinicoScribe 项目的关注！我们欢迎各种形式的贡献。

## 如何贡献

### 1. 提交 Issue

如果您发现 bug 或有新功能建议，请先检查是否已有相关 issue。

- 使用清晰的标题
- 详细描述问题或需求
- 如果是 bug，请提供复现步骤和环境信息

### 2. 提交代码

1. Fork 本仓库
2. 创建您的分支 (`git checkout -b feature/AmazingFeature`)
3. 提交您的更改 (`git commit -m 'Add some AmazingFeature'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 打开 Pull Request

### 3. 代码规范

- 使用 Black 格式化代码：`black src/`
- 遵循 PEP 8 规范
- 添加适当的注释和文档字符串
- 确保通过所有测试：`pytest`

### 4. 特别需要的贡献

- **医疗专业内容**：病历模板、医学术语词表、科室特定需求
- **多语言支持**：英文、日文等病历格式
- **前端界面**：Web UI 或桌面客户端
- **医院 HIS 对接经验**：HL7 FHIR 实施经验分享

## 安全报告

如果您发现安全漏洞，请发送邮件至 security@clinico-scribe.dev，不要公开提交 issue。

## 行为准则

- 尊重所有参与者
- 欢迎新手提问
- 就事论事，保持专业
